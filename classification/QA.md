# Classification Q&A — Thai preparation

## 1. Classification ต่างจาก segmentation อย่างไร?

Classification ให้ชื่อชนิดเนื้องอกหนึ่งคลาสต่อภาพ ส่วน segmentation ให้ mask บอกตำแหน่งเนื้องอกในระดับพิกเซล โมเดลของเราทำทั้งสองงานและเรียนรู้ encoder ร่วมกัน

## 2. ทำไมใช้ Macro-F1 แทนการดู accuracy อย่างเดียว?

จำนวนภาพแต่ละคลาสไม่เท่ากัน โดย glioma มีมากที่สุด Accuracy ให้น้ำหนักกับทุกภาพเท่ากัน ขณะที่ Macro-F1 คำนวณ F1 ของแต่ละคลาสแล้วเฉลี่ย ทำให้แต่ละชนิดมีน้ำหนักเท่ากัน เรารายงานทั้งสองค่าเพื่อให้เห็นภาพครบ

## 3. Precision กับ Recall ต่างกันอย่างไร?

Precision ถามว่า “ภาพที่โมเดลบอกว่าเป็นคลาสนี้ ถูกจริงกี่ส่วน” ส่วน Recall ถามว่า “ภาพจริงของคลาสนี้ โมเดลหาเจอกี่ส่วน” เช่น ถ้าดู meningioma ให้ถือ meningioma เป็น positive และอีกสองคลาสเป็น negative

## 4. Macro-F1 คำนวณจาก macro precision กับ macro recall ได้เลยไหม?

โดยทั่วไปไม่ได้ ต้องคำนวณ F1 ของแต่ละคลาสก่อนแล้วเฉลี่ย ผลจึงไม่จำเป็นต้องเท่ากับ harmonic mean ของ macro precision และ macro recall

## 5. ทำไมใช้ cross-entropy?

แต่ละภาพมี label หนึ่งคลาสจากสามคลาส Cross-entropy ลงโทษโมเดลเมื่อให้ความน่าจะเป็นกับคลาสจริงต่ำ ในโค้ดส่ง logits เข้า loss โดยตรง ไม่ต้องทำ softmax ก่อน

## 6. Classification head รับ mask ด้วยหรือไม่?

ไม่รับครับ รับคุณลักษณะจาก encoder ที่อ่านภาพ MRI ส่วน mask เป็นเป้าหมายสำหรับสอน segmentation branch ตอนฝึก ความรู้จากงาน segmentation ส่งถึง classifier ผ่าน encoder ที่แชร์กัน

## 7. ทำไม segmentation อาจช่วย classification?

สมมติฐานคือ mask supervision อาจช่วยให้ shared encoder เรียนรู้คุณลักษณะของบริเวณเนื้องอกที่ใช้จำแนกชนิดได้ดีขึ้น เราพบคะแนน classification ดีขึ้นในผลที่บันทึกไว้ แต่ยังไม่ได้ทดสอบกลไกนี้ด้วย attention maps หรือการทดลองเฉพาะ จึงเป็นคำอธิบายที่เป็นไปได้

## 8. คลาสไหนยากที่สุด?

Meningioma มี F1 ต่ำที่สุดใน A, C และ D บน test split นี้ ใน C ค่า F1 เฉลี่ยประมาณ 0.889 เทียบกับ glioma 0.994 และ pituitary 0.931 จึงควรระบุว่าเป็นผลของชุดทดสอบนี้

## 9. Confusion matrix อ่านอย่างไร?

แถวคือคลาสจริง คอลัมน์คือคลาสที่โมเดลทำนาย แนวทแยงคือคำตอบถูก ช่องอื่นคือการสับสน รูปของทีมรวมผลจากสาม seeds จึงมี 1,308 predictions จากภาพเดิม 436 ภาพ ไม่ใช่ภาพอิสระ 1,308 ภาพ

## 10. ทำไม meningioma ถูกทายเป็น pituitary?

ตาราง error analysis แสดงว่าผู้ป่วยกลุ่ม 103673 มี 18 ภาพที่ผิดทุก seed รวม 54 ครั้งในแต่ละโมเดล รายงานเดิมเสนอว่าตำแหน่งและลักษณะคล้าย pituitary เป็นเหตุที่เป็นไปได้ หากถามถึงสาเหตุทางรังสีวิทยาที่ได้รับการยืนยัน ให้ตอบว่า “I don't know” และอธิบายว่าข้อมูลที่มีไม่ยืนยันสาเหตุนี้

## 11. +0.022 Macro-F1 มีนัยสำคัญหรือไม่?

I don't know. เรายังไม่ได้ทำการทดสอบนัยสำคัญที่เหมาะสม คะแนนเพิ่มขึ้นทั้งสาม seeds เป็นหลักฐานสนับสนุนบน split นี้ แต่มี test เพียง 29 patient groups และสาม seeds ไม่ใช่ผู้ป่วยใหม่สามชุด แนวทางต่อไปคือการประเมินข้าม patient splits และ confidence interval ที่คำนึงถึงกลุ่มผู้ป่วย

## 12. การเปรียบเทียบยุติธรรมแค่ไหน?

ใช้ architecture, split และค่าฝึกหลักร่วมกัน แต่ learning rate ถูกเลือกจาก C แล้วนำไปใช้กับ A/D และเกณฑ์เลือก checkpoint ของ A กับ multi-task ต่างกันตามงาน จึงยังมีข้อจำกัด และการใช้ seed label เดียวกันไม่ได้ยืนยันว่า augmentation ทุกครั้งตรงกัน

## 13. ทำไม D ไม่ชนะ C?

ผลที่บันทึกไว้แสดงว่า D มี Macro-F1 เฉลี่ยต่ำกว่า C แต่สาเหตุที่แน่ชัดยังไม่ทราบ รายงานเดิมสังเกตว่าน้ำหนักสองงานยังใกล้กัน ควรให้ผู้รับผิดชอบหัวข้อ 4 อธิบายกราฟน้ำหนัก ไม่ควรสรุปว่า uncertainty weighting ใช้ไม่ได้กับทุกปัญหา

## 14. ตัดผู้ป่วยที่ทายผิดออกแล้วรายงานคะแนนได้ไหม?

คะแนนหลักต้องรวม test set เดิมทั้งหมด การดูผลเมื่อตัดกลุ่มนั้นออกใช้ได้เป็นการวิเคราะห์ความไวหลังการทดลอง โดยต้องระบุให้ชัด และไม่ใช้คะแนนนั้นแทนผลหลัก

## 15. ใช้กับภาพสมองปกติหรือใช้จริงในโรงพยาบาลได้ไหม?

โมเดลไม่มีคลาสสมองปกติ จึงจะเลือกหนึ่งในสามชนิดเนื้องอกเมื่อให้ภาพเข้าไป เรายังไม่ได้ประเมินในข้อมูลภายนอกหรือการใช้งานจริง จึงสรุปได้เฉพาะงานวิจัยใน dataset นี้

## 16. ตรวจสอบผลใน folder นี้อย่างไร?

report.py คำนวณ mean, sample SD และความต่างราย seed จาก CSV เดิม แล้วเทียบกับ summary_test.csv พร้อมบันทึก SHA-256 ของแหล่งข้อมูล การตรวจนี้ยืนยันการคำนวณตาราง ไม่ได้ยืนยันการเทรนซ้ำ เพราะข้อมูลและ checkpoints ไม่อยู่ใน repo
